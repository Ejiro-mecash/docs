Use this endpoint to retrieve the banks available for a given **country** and **currency** pair. It is not limited to Nigeria: it works for every country we support, so you can look up banks for any destination before creating a payout.

The list you get back depends on the two query parameters you send:

- `currency`: the currency you want to send.
- `country`: the country where the destination bank is located.

## Endpoint

**`GET`** `{baseurl}/v1/bank?currency={currency}&country={country}`

## Currency and country combinations

Currency and country are independent, so you can send a currency to a bank in any supported country. For example:

| **You want to send** | **To a bank in** | **`currency`** | **`country`** |
| :------------------- | :--------------- | :------------- | :------------ |
| Nigerian Naira       | Nigeria          | `NGN`          | `NG`          |
| US Dollars           | South Africa     | `USD`          | `ZA`          |
| US Dollars           | France           | `USD`          | `FR`          |
| Euros                | France           | `EUR`          | `FR`          |
| Euros                | United States    | `EUR`          | `US`          |

<Note>
  Use two-letter ISO country codes (for example `NG`, `ZA`, `FR`, `US`) and three-letter currency codes (for example `NGN`, `USD`, `EUR`). Only currency and country combinations that we support will return banks.
</Note>

## Request example

### Naira to a bank in Nigeria

```sh
curl --location '{baseurl}/v1/bank?currency=NGN&country=NG' \
--header 'x-api-key: API_KEY:API_KEY_HERE'
```

### US Dollars to a bank in South Africa

```sh
curl --location '{baseurl}/v1/bank?currency=USD&country=ZA' \
--header 'x-api-key: API_KEY:API_KEY_HERE'
```

### Euros to a bank in France

```sh
curl --location '{baseurl}/v1/bank?currency=EUR&country=FR' \
--header 'x-api-key: API_KEY:API_KEY_HERE'
```

### Headers

| **Header Name** | **Value**             | **Required** | **Description**            |
| :-------------- | :-------------------- | :----------- | :------------------------- |
| `x-api-key`     | `API_KEY:API_KEY_HERE` | Yes          | API key for authentication |

### Query parameters

| **Parameter** | **Example** | **Required** | **Description**                                                  |
| :------------ | :---------- | :----------- | :--------------------------------------------------------------- |
| `currency`    | `USD`       | Yes          | Currency you want to send (for example `NGN`, `USD`, `EUR`)      |
| `country`     | `ZA`        | Yes          | Country of the destination bank (for example `NG`, `ZA`, `FR`)   |

## Successful response (200 OK)

For example, to get banks in South Africa for USD payouts:

```
GET https://api.me-cash.com/v1/bank?country=ZA&currency=USD
```

```json
{
  "message": "recipient bank details fetched successfully",
  "status": "success",
  "data": [
    {
      "bankName": "NEDBANK LIMITED",
      "sortCode": "04127",
      "swiftCode": "NEDSZAJJXXX"
    }
  ]
}
```

The response above is shortened to one bank. The `data` array contains every bank available for the country and currency you requested.

### Response fields

<ResponseField name="message" type="string">
  Human-readable result of the request.
</ResponseField>

<ResponseField name="status" type="string">
  Status of the request, for example `success`.
</ResponseField>

<ResponseField name="data" type="array">
  List of banks available for the requested country and currency.

  <Expandable title="bank properties">
    <ResponseField name="bankName" type="string">
      Name of the bank.
    </ResponseField>

    <ResponseField name="sortCode" type="string">
      Bank code. Use this value as the `sortCode` when verifying an account or creating a payout.
    </ResponseField>

    <ResponseField name="swiftCode" type="string">
      SWIFT/BIC code of the bank. Example: `NEDSZAJJXXX`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Error responses

| **Status Code** | **Description**                                               | **Response Body Example**             |
| :-------------- | :------------------------------------------------------------ | :------------------------------------ |
| `401`           | The API key is missing or invalid.                            | "Invalid API key"                     |
| `400`           | A required query parameter is missing or invalid.             | "Missing required parameter: country" |
